# seokpan-hybrid-app

석판 2차 프로젝트의 검증 서비스 이관과 ROSA 환경 적용을 위한 Frontend·Backend 코드, 테스트 및 이미지 빌드 저장소입니다. 1차에서 상속한 Source와 2차의 변경·기여를 구분하고, 데이터·권한·TLS·Runtime State 연결과 대표 업무 흐름을 검증할 계획입니다.

현재는 초기 구성 단계입니다. 실제 이관 코드와 Build·Run·검증 근거는 구현에 맞춰 연결합니다.

Migration Seed·저장소 책임·검증 기준은 [2차 상세설계](https://github.com/seokpan/seokpan-hybrid-docs/blob/main/design/03_DETAILED_DESIGN.md)에서 확인합니다.
