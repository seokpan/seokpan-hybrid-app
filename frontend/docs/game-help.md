  목업 01-6의 배경 유지 모달과 5단계 흐름을 참고하고 자세한 규칙은 별도로 펼친다.

  흑 금수, Pass/공동 패배/무승부/몰수/경기 무효, 재접속·방장 승계를 구분한다.
- 안내를 열어도 타이머·게임·채팅은 멈추지 않는다. HTTP 요청이나 상태 변경을 실행하지 않는다.
  닫기/Escape 후 원래 버튼으로 초점을 돌리고 Tab이 창 안에서 순환하도록 처리한다.
- 신원·경로 변경 시 열린 안내를 정리한다. 작은 화면은 세로 단계 목록·모달 내부 스크롤을 사용한다.
